# Sur la piste des loups – tableau de rétro

Tableau de rétrospective d'équipe sur le thème des loups.

Colonnes : Ce qui a bien marché · Ce qui nous a freinés · Ce qu'on a appris · Bravo et remerciements · Ce qu'on fait ensuite.

## Utilisation
1. Chaque participant écrit ses notes (elles restent dans son navigateur).
2. Il clique sur **Envoyer mes notes** et transmet le code `MEUTE:…` à l'animateur.
3. L'animateur clique sur **Importer des notes**, colle tous les codes et obtient le tableau complet.

Aucun serveur : tout fonctionne en local dans le navigateur.
